A single-line office joke, written by `main.py` to `/output/entry.txt`.

> I put 'per my last email' in my will so my family knows I meant it.

## Files

- `main.py` — stdlib-only entrypoint; writes the 67-character joke (UTF-8, no trailing newline) to `/output/entry.txt`.
- `README.md` — this file.
- `LICENSE` — MIT license.

## Run

```sh
python3 -P -s main.py
```

## Tests

```sh
python3 -m unittest discover -s ../tests -v
```
